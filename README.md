# KANNIGTHA

Landing page for four real-time 3D worlds that run in a browser tab.

| Game | What it is | Status |
|---|---|---|
| [Skärgård](https://skargard.vercel.app) | Fly the Swedish archipelago, rebuilt to scale from real LiDAR + OpenStreetMap. WebXR on Quest 3 | Live |
| [Blacksite](https://javieranta.github.io/blacksite/) | Tactical FPS with **zero external assets** — every texture, mesh and sound generated in code | Live |
| Neon Grid | Synthwave 3D maze chase on an endless neon plain | In development |
| Alpine | Ski the real Megève domain, from 1m IGN LiDAR | In development |

Static site — one `index.html`, no build step. Screenshots in `shots/` are real
in-engine captures from each game's own headless screenshot rig, not mock-ups.

## Local

```bash
npx serve .
```
